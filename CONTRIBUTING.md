# Contribuição

Siga o ambiente e os comandos de verificação do README. Para corrigir um bug, descreva como reproduzi-lo com contas fictícias, faça uma mudança focada e exercite o fluxo real. Para uma funcionalidade, identifique o serviço responsável e preserve as verificações de empresa e permissão.

Rode `python verify_preview.py` no ambiente instalado e informe no PR o comportamento antes e depois, os testes executados e as limitações. Não anexe o arquivo privado de configuração, bancos, dados de clientes, exportações ou imagens do produto comercial. Consulte o [README](README.md#autoria-e-licenças) para identificar a licença aplicável a cada material.
